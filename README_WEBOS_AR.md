# الكتاب الموقوت — نسخة LG webOS
نسخة تجريبية مخصصة لتلفزيونات LG webOS بما فيها 65UR78006LL، إلى جانب نسخة Android TV الموجودة بالمستودع.

بناء LG: افتح [GitHub Actions](https://github.com/MSN1972/Al-Kitab-Al-Mawqut/actions/workflows/webos-ipk.yml) ثم نزّل IPK من آخر بناء ناجح ضمن Artifacts. لا يمكن تثبيت IPK من USB مباشرة؛ تحتاج Developer Mode الرسمي وwebOS CLI على حاسوب متصل بالشبكة ذاتها.

مصدر التطبيق محفوظ في webos-source.tar.xz، ويمكن فكّه محلياً بالأمر `tar -xJf webos-source.tar.xz`. وتتوفر نسخة ZIP للمصدر في محادثة العمل.

- مكة المكرمة وتوقيت Asia/Riyadh
- طريقة حساب أم القرى 4 عبر AlAdhan مع تخزين الشهر للعمل دون اتصال بعد التحميل
- تعديل فواصل الإقامة ومدد الصلاة 5–7 دقائق من الريموت
- خلفية كحلية ثابتة أثناء الصلاة، بلا حركة أو نصوص
- ثلاثة أحاديث صحيحة موثقة وشريط متحرك
- صورة الكعبة (4096×2510)، LaachirDeeper، [CC0](https://commons.wikimedia.org/wiki/File:Kaaba_Al-Musharrafah.jpg)، يتم تنزيلها أثناء البناء

النسخة **لم تُختبر على شاشة LG فعلية**، ومواقيتها الحسابية يجب مقارنتها بجدول المسجد المعتمد قبل استخدامها.
