# الكتاب الموقوت — إصدار Android TV 0.9.0-beta

يجمع أذكار ما بعد الصلاة الثلاثة في **شاشة واحدة ثابتة** مع مصادرها الصحيحة، وخلفية كحلية وإطارات ذهبية، دون أي تبديل صفحات. تظل مدة عرض الأذكار قابلة للتعديل ثم تعود الشاشة تلقائياً لمواقيت الصلاة.

تغيير البلد وطريقة الحساب بغرض الاختبار محفوظ، ولا ينبغي مقارنة مواقيت مدينتين أو طريقتي حساب مختلفتين. التحقق من تقويم المسجد الرسمي ضروري قبل التشغيل الفعلي.
