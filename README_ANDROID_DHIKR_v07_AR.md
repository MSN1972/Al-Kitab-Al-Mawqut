# نسخة Android TV 0.7.0-beta — أذكار ما بعد الصلاة

- أصبحت شاشة الأذكار كحلية داكنة مع إطار ذهبي ونص أبيض عاجي كبير ومصادر واضحة.
- تُعرض ثلاثة نصوص موثقة تباعاً، بدلاً من بطاقات زرقاء صغيرة مزدحمة:
  1. الاستغفار والدعاء بعد السلام — صحيح مسلم 591.
  2. التهليل والدعاء — صحيح البخاري 844.
  3. التسبيح والتحميد والتكبير، وختام المائة — صحيح مسلم 597.
- مدة عرض الأذكار من إعدادات التطبيق كما كانت؛ أول 25% للاستغفار، ثم 25% للدعاء، ثم 50% للتسبيح.
- لا حركة ولا صوت في شاشة الأذكار؛ الانتقال بين الصفحات يتم بتبديل ثابت وفق الوقت.
- يتم الإبقاء على الانتقال: إقامة -> شاشة صلاة هادئة -> أذكار -> العودة إلى المواقيت.
- لا يُغيّر هذا التحديث حساب مواقيت مكة أو بيانات الإقامة المحفوظة.

**التثبيت:** نزّل APK التجريبي من آخر بناء ناجح في GitHub Actions وانقله إلى Google TV بالطريقة السابقة. التحديث يحمل applicationId نفسه ورقم إصدار أعلى، لكن تثبيت تحديث APK يتطلب أيضاً تطابق توقيع النسخة الأصلية. إن ظهر تعارض في التوقيع فلا تحذف التطبيق قبل توثيق إعداداته.
