# الكتاب الموقوت — نسخة المتصفح لشاشات LG

شاشة LG 65UR78006LL تعمل بنظام webOS، ولا يمكنها تثبيت ملف Android APK. تم تجهيز نسخة HTML تعمل من متصفح التلفزيون باستخدام نفس واجهة webOS، مع تحميل وتخزين المواقيت.

## نشر الشاشة في GitHub Pages
الإجراء المطلوب لمرة واحدة من مالك المستودع:
- افتح Settings → Pages في المستودع.
- ضمن Build and deployment اختر Source = GitHub Actions.
- ثم شغّل workflow **Publish LG browser preview** من تبويب Actions، أو ادفع تعديلاً على ملفات الموقع.

سيصبح رابط العرض بعد نجاح النشر:
https://msn1972.github.io/Al-Kitab-Al-Mawqut/

## ضمانات البيانات
- يقوم GitHub Actions بتنزيل مواقيت شهر سابق وحالي وتالٍ حسب توقيت مكة، والتحقق من اكتمال الأيام وتوقيت كل صلاة.
- تُحفظ المواقيت داخل الموقع عند كل بناء وتُحفظ في متصفح التلفزيون. يُعاد بناء الموقع تلقائياً يومياً.
- في حال تعذر التحميل لن تُعرض أوقات مختلقة.
- تتبع الحسابات طريقة أم القرى (method 4) عبر AlAdhan؛ يجب مقارنتها بالمواقيت الرسمية للمسجد قبل الاستخدام في الصلاة.
- عند انتهاء العد التنازلي للإقامة تختفي العناصر المتحركة تماماً وتظهر شاشة كحلية داكنة لمدة 5 إلى 7 دقائق قابلة للتعديل.
- صورة الكعبة المصدر Wikimedia Commons بترخيص CC0.
- هذه نسخة **تجريبية**، وقد يختلف دعم الشاشة الكاملة في متصفح تلفزيون LG باختلاف النظام.
