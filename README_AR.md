# الكتاب الموقوت — Android TV (v0.5.0-beta)

تطبيق مجاني لمساجد المسلمين، يعرض توقيت مكة المكرمة ومواقيت الصلاة المحسوبة بطريقة أم القرى (method=4) مع إمكانية تعديل **فاصل الإقامة** يدوياً. يعرض 3 أحاديث صحيحة موثقة، ويخفي كل عناصر الشاشة أثناء الصلاة لمدة 5–7 دقائق افتراضياً (قابلة للتعديل). التطبيق تجريبي ولم يختبر بعد على تلفزيون فعلي.

## APK التجريبي

افتح تبويب Actions في هذا المستودع، ثم اختر Build Android TV APK. افتح أحدث تشغيل ناجح واختر Artifacts > Al-Kitab-Al-Mawqut-Debug-APK. يحتوي الملف المضغوط على `app-debug.apk`. يتطلب التلفزيون Android TV 8.0 أو أحدث والسماح بتثبيت تطبيقات غير معروفة المصدر.

**تنبيه**: لا تنشر APK العام قبل المقارنة بالجدول الرسمي لمواقيت المسجد. التطبيق يحتاج اتصالاً عند أول تشغيل لتحميل تقويم الشهر، ثم يحفظ البيانات محلياً. طريقة الحساب من خدمة AlAdhan وليست توثيقاً مستقلاً لجدول أم القرى الرسمي.

## صورة الكعبة

بناء GitHub Actions يحاول تنزيل صورة حقيقية للكعبة تحمل ترخيص CC0 من Wikimedia Commons (المؤلف Farazbinyusuf، مارس 2025): https://commons.wikimedia.org/wiki/File:Al-Kaaba_in_Mecca.jpg . إذا فشل التنزيل سيبني التطبيق بخلفية كحلية احتياطية. الصورة الأصلية ليست 4K؛ يمكن استبدالها بصورة مُرخّصة أعلى دقة في إصدار لاحق.

## حدود النسخة

- لا تزال تفتقر إلى 50 حديثاً وإلى تعديل وقت الأذان نفسه.
- ضبط الإقامة حالياً بالدقائق بعد الأذان وليس بوقت ساعة ثابت.
- ملفات APK من Actions موقّعة بمفتاح debug وليست صالحة للنشر على Google Play.
- لا يوجد تشغيل تلقائي بعد إقلاع التلفزيون؛ يحتاج دعماً من نوع جهاز Android TV.
