# الكتاب الموقوت — تطبيق Android للهاتف (0.1.0-beta)

تطبيق مستقل لهواتف Android، مصمم للشاشة العمودية واللمس. لا يستبدل تطبيق Android TV ولا يؤثر على تطبيق LG.

## الوظائف المتاحة
- الساعة والتاريخ الميلادي والهجري على خلفية الكعبة (عند توفر الصورة)
- مواقيت الصلوات الخمس، والإقامة والعد التنازلي
- مكة المكرمة / تقويم أم القرى افتراضياً
- اختيار بلد ومدينة وطريقة حساب أخرى للاختبار، وحفظ الاختيار
- ضبط دقائق الإقامة بعد الأذان بشكل مستقل لكل صلاة
- أذكار ما بعد الصلاة كاملة، في صفحة واحدة قابلة للتمرير على الهاتف، مع المراجع
- حفظ مواقيت شهرية للعمل بعد انقطاع الاتصال عند توفرها مسبقاً

## حدود الإصدار
- هذه نسخة تجريبية وليست تطبيق متجر Google Play النهائي.
- لا توجد تنبيهات أذان أو إشعارات خلفية بعد؛ تجنب إضافة صلاحيات غير مطلوبة.
- المواقيت من خدمة aladhan API وفق المدينة وطريقة الحساب المختارة. يجب مقارنتها بالتقويم الرسمي أو المسجد المحلي قبل اعتمادها.
- تاريخ HijrahDate الهجري قد يختلف يوماً عن الإعلان المحلي.
- مواقيت الإقامة أمثلة افتراضية قابلة للتعديل وليست مواقيت أي مسجد بعينه.
- مساحة عمل مصدرية مشتركة مع Android TV عبر Gradle sourceSets بهدف عدم تكرار محرك المواقيت.

## بناء النسخة
يؤدي GitHub Actions باسم "Build Android Mobile APK" إلى إنشاء `mobile-debug.apk` داخل artifact مستقل.

قد تحتاج إلى السماح بالتثبيت من الملفات أو المتصفح على الهاتف. لا تثبّت إلا من ملف المستودع.
