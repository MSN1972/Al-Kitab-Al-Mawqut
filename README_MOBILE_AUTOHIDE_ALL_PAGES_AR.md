# الكتاب الموقوت — 0.1.8-beta

شريط أزرار المواقيت والأذكار والإعدادات مخفي افتراضياً في جميع الصفحات. يظهر باللمس أو حركة مؤشر الماوس، ويختفي تلقائياً بعد خمس ثوانٍ من آخر تفاعل. عند الانتقال بين الصفحات يبدأ العد مجدداً. تبقى منطقة المحتوى والتمرير متاحة ولا تُعدل حسابات الصلاة أو الأذكار أو الألوان أو الأيقونة.
