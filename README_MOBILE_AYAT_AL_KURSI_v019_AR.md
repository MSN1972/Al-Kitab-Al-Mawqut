# الكتاب الموقوت 0.1.9-beta

إضافة آية الكرسي كاملة إلى شاشة أذكار الجوال بعد التسبيح وقبل المعوذات، مع توثيق سورة البقرة (255) والسنن الكبرى للنسائي. يُعرض النص القرآني بخط واضح قابل للتمرير والتكيّف مع الشاشات، مستلهماً ملصق الأذكار المرفق دون استنساخه كصورة صغيرة وغير مقروءة. لا تعديل على خوارزمية المواقيت أو إعدادات الإقامة أو إخفاء أزرار التنقل.
