# تحسين واجهة الجوال — 0.1.2-beta

- المحافظة على منطقة الأمان حول شريط التنقل وأزرار التبويب السفلي.
- تقليل ارتفاع صورة الكعبة وبطاقات الصلاة والهوامش لإظهار بيانات أكثر.
- تحسين تنسيق أذكار الجوال مع التمرير العمودي الطبيعي على الشاشة الصغيرة؛ لا يتم حذف أي ذكر أو مصدر.
- زيادة تباين نصوص وحقول إدخال المدينة والبلد وإيضاح زر البحث.
- تنسيق أزرار (+/-) وفق الكحلي والذهبي؛ تبقى إعدادات كل صلاة محفوظة.
- يحتفظ كل من حساب المواقيت، المنطقة الزمنية، وأسماء المذاهب/طرق الحساب بسلوكه الحالي؛ لم تتغير خوارزميات الصلاة.
- شريط التنقل السفلي داخل مساحة العرض الآمنة؛ إعدادات تكبير العرض في النظام قد تؤثر بصرياً على الحجم.

نسخة مراجعة مستقلة لأجهزة Android، ولا تؤثر على بناء TCL/LG.
